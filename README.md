# Dominoreef 1.0 TEST
Native Java/Canvas Android 8+ Norinuri domino-island puzzle.

Shade unnumbered cells to make isolated two-cell dark dominoes. Dominoes may touch at corners, never edges. Every edge-connected white island must contain exactly one numbered clue, and that clue gives the island size. Clue cells stay white. There is no dark connectivity requirement or predefined room quota. Twelve distinct 4x4 clue boards have twelve distinct unique solutions.

Saved island palette and cell guides, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens browser.

Independent Java per-dark-cell partner degrees and coordinate-list white components agree with production bitset component-size and island-clue checks on all 65536 masks per board. Exactly one solution per board; fixed clues, bounds, solve, undo and replay pass. Adapter navigation, saved settings, privacy, cell taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current 803-entry registry, 126 partial recovered README records and exact Gazefen cumulative stage found no Norinuri or Norikabe match. Shares isolated dark dominoes with Twinmarsh/Norinori, but replaces predefined room shade quotas with emergent numbered white-island sizes. Unlike Letterhaven/Dominion matching letter pairs, every white component has exactly one fixed numeric size clue. Unlike Reefhaven/Nurikabe connected sea and no-2x2 checks, all dark components here are isolated dominoes. Known Norinuri genre, not a global invention. Partial corpus, not ALL-local. Rules https://www.janko.at/Raetsel/Norinuri/index.htm .
